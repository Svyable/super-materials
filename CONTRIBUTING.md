# Contributing

Contributions are welcome if they make the hypotheses more falsifiable or reproducible.

For a new candidate, include: exact formula; structure file or explicit coordinates; pressure/temperature domain; convex-hull/phonon evidence if available; DOS and EPC assumptions; an uncertainty range; predicted structural and spectroscopic fingerprints; a synthesis route; and a fast falsifier.

Do not merge language that converts a model prediction into an experimental claim. Raw data, provenance, negative results, and independent replications are first-class contributions.
